Data Cleaning — step-by-step SQL

Use the queries below to detect and fix missing, invalid or duplicate data. Click Explain Query under each block to see line-by-line reasoning.

Step 1 — Find missing values

SELECT *
FROM ratings
WHERE rating IS NULL OR movie_id IS NULL OR user_id IS NULL OR rating_date IS NULL;

Step 1b — Example: fill missing values

UPDATE ratings
SET rating = 3.5
WHERE movie_id = 2 AND user_id = 103 AND rating IS NULL;

UPDATE ratings
SET rating = 4.0
WHERE movie_id = 10 AND user_id = 101 AND rating IS NULL;

UPDATE ratings
SET rating_date = CURDATE()
WHERE movie_id = 5 AND user_id = 105 AND rating_date IS NULL;

Step 2 — Find invalid ratings outside 1–5

SELECT *
FROM ratings
WHERE rating < 1 OR rating > 5;

Step 2b — Fix invalid ratings

UPDATE ratings
SET rating = 4.7
WHERE movie_id = 1 AND user_id = 101 AND rating = 6.0;

UPDATE ratings
SET rating = 4.5
WHERE movie_id = 6 AND user_id = 106 AND rating = 0;

Step 3 — Detect duplicates

SELECT movie_id, user_id, rating_date, COUNT(*) AS cnt
FROM ratings
GROUP BY movie_id, user_id, rating_date
HAVING cnt > 1;

Step 3b — Remove duplicates (keep first)

DELETE FROM ratings
WHERE rating_id IN (
  SELECT rating_id FROM (
    SELECT rating_id,
           ROW_NUMBER() OVER (PARTITION BY movie_id, user_id, rating_date ORDER BY rating_id) AS rn
    FROM ratings
  ) t
  WHERE rn > 1
);
Note: the nested SELECT helps MySQL avoid deleting from the same table used in a subquery.

Step 4 — Verify data quality

SELECT * FROM ratings WHERE rating IS NULL OR rating_date IS NULL;
SELECT * FROM ratings WHERE rating < 1 OR rating > 5;
SELECT movie_id, COUNT(*) AS total_ratings
FROM ratings
GROUP BY movie_id;

Analysis — Key SQL queries & reasoning

Q1 — Top Movies by Average Rating

SELECT m.title, ROUND(AVG(r.rating),2) AS avg_rating, COUNT(r.rating) AS total_ratings
FROM ratings r
JOIN movies m ON r.movie_id = m.movie_id
GROUP BY m.title
ORDER BY avg_rating DESC, total_ratings DESC;

Q2 — Most Active Users

SELECT u.name, COUNT(r.rating) AS total_ratings, ROUND(AVG(r.rating),2) AS avg_rating_given
FROM ratings r
JOIN users u ON r.user_id = u.user_id
GROUP BY u.name
ORDER BY total_ratings DESC;

Q3 — Ratings by Genre

SELECT m.genre, ROUND(AVG(r.rating),2) AS avg_rating, COUNT(r.rating) AS total_ratings
FROM ratings r
JOIN movies m ON r.movie_id = m.movie_id
GROUP BY m.genre
ORDER BY avg_rating DESC;

More analysis

Q4 — Ratings Trend Over Time

SELECT DATE(r.rating_date) AS date, ROUND(AVG(r.rating),2) AS avg_rating, COUNT(*) AS total_ratings
FROM ratings r
GROUP BY DATE(r.rating_date)
ORDER BY date;

Q5 — Country-wise Behavior

SELECT u.country, COUNT(r.rating) AS total_ratings, ROUND(AVG(r.rating),2) AS avg_rating
FROM ratings r
JOIN users u ON r.user_id = u.user_id
GROUP BY u.country
ORDER BY total_ratings DESC;

Q6 — Most Rated Movies (Popularity)

SELECT m.title, COUNT(r.rating) AS rating_count
FROM ratings r
JOIN movies m ON r.movie_id = m.movie_id
GROUP BY m.title
ORDER BY rating_count DESC;

Visualization — export & Tableau steps

Export cleaned dataset for Tableau or Excel:

SELECT r.rating_id, r.movie_id, m.title, m.genre, m.release_year,
       r.user_id, u.name AS user_name, u.age, u.country,
       r.rating, r.rating_date
FROM ratings r
JOIN movies m ON r.movie_id = m.movie_id
JOIN users u ON r.user_id = u.user_id;

What we learned — Insights & Recommendations

  • Top-performing genres: Sci-Fi and Drama—prioritize those in acquisitions and promotions.
  • Power users: Reward most active users (loyalty badges / discount codes) to retain engagement.
  • Country focus: USA & India produce most ratings—localize marketing and content for those markets.
  • Data quality: Enforce rating range and required dates at ingestion to avoid manual cleaning.
  • Product ideas: Use top-rated lists for personalized recommendations and seasonal campaigns around peak months.
